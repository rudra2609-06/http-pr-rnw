Node demo

Serve HTML files in seconds

This mini HTTP playground lets you wire up routes, drop in new markup, and refresh the browser to see the latest response instantly.

View release notes

Minimal stack

Only the native http and fs modules are used so you can focus on routing concepts.

Instant feedback

Save a file, refresh the page, and the server responds with your updated HTML without restarting the process.

Route clarity

Each navigation link maps directly to a file, which keeps the control flow easy to read for new contributors.

Quick start

  1. Run node index.js.
  2. Visit http://localhost:8087 in your browser.
  3. Edit any HTML page and refresh to see the new response.
